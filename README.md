# Discord Bot — Community Server

Многофункциональный бот для сервера общения и ивентов: верификация, модерация,
учёт ПТ, Anti-Nuke, снапшоты, репорты, заявки в стафф, ИИ-анализ.

## Стек
- Python 3.11, discord.py 2.x
- SQLite (aiosqlite)
- systemd на Ubuntu 22.04/24.04

## Установка

```bash
git clone https://github.com/BitStopSU/ds_bot.git /opt/discord-bot
cd /opt/discord-bot
chmod +x setup.sh manage.sh
./setup.sh
```
